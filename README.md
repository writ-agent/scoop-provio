# Scoop bucket for provio

[provio](https://github.com/writ-agent/provio): a safety floor your AI agents can't get under.

```powershell
scoop bucket add provio https://github.com/writ-agent/scoop-provio
scoop install provio
provio scan
```

The manifest installs the prebuilt release binary, checked against the
release's `checksums.txt`. It is generated by `scripts/gen_distribution.py`
in the main repository.
